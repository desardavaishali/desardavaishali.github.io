About

I’m Vaishali.

I make sure software actually works. That’s the dinner-table answer and it’s also the accurate one.
The longer version: 15+ years across fintech, regulated digital health, and enterprise platforms. Six years in London. Before and after that, India. Multiple clients, multiple teams, multiple kinds of delivery pressure - and through all of it, the same stubborn curiosity about where things actually break versus where everyone assumes they won’t.
I’m not the person who runs the checklist. I’m the person who looks at the checklist and asks what it’s assuming.

What I’ve learned that nobody teaches: Most software failures aren’t dramatic. There’s no crash, no alert, no obvious error. There’s a confirmation message that fired while nothing saved. An API that doesn’t enforce what the UI restricts. A test suite that looks complete because it covers everything that was specified - and misses everything that wasn’t.
AC passes. Integration “should just work.” AI said it’s done so it’s done.
I’ve spent 15+ years in rooms where those assumptions went unchallenged. My job - the part that feels most like me - is catching the thing nobody else saw before it shipped.

Work

I build things for the problems I face and write about.

Right now I’m working on multiple AI agents - some in alpha, some in beta. The one that’s been out the longest is an AI-powered reviewer for test suites: something that does what a senior QA lead does in review - spots the gaps, questions the assumptions, flags what looks complete but isn’t. It’s being shaped by real feedback from real practitioners. I’m also writing about where AI meets quality engineering - what’s actually changing, what people are getting wrong, and what 15+ years of watching software break teaches you that no model can generate.

Earlier work - A few open source tools that started as solutions to real problems on real projects:

  • JSON Compare - for comparing JSON objects. Sounds simple, saves hours.
  • API Automation with Serenity Screenplay - API testing using Serenity screenplay pattern.
  • Email Validation with Mailinator - validates emails using Mailinator. Built for a specific gap, useful beyond it.

These are boilerplate examples of more advanced versions I’ve built for clients. If you need something customised, let’s talk.
